<h1 aling="center">Twitter Clone</h1>

A simple front-end **Twitter clone** inspired by the classic Twitter layout.  
The project focuses on **SVG, Canvas, and image usage** of the Twitter bird logo.

## ✨ What this project shows

- Classic Twitter-style layout  
- Twitter bird logo in multiple formats:
  - PNG
  - SVG
  - Canvas rendering
- Clickable SVG logo with **copy-to-clipboard** functionality
- Clean project structure using HTML, CSS, and JavaScript
